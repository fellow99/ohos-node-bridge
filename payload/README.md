# 载荷（Node 侧 JS，随库分发）

本目录是**库自带的 Node 侧脚本**（纯 JS，不参与 ArkTS 编译）：

| 文件 | 作用 |
| --- | --- |
| `bootstrap.js` | 消费方入口的**参考实现**：解析环境、装配日志与宿主桥、按约定加载真正的应用入口 |
| `selfcheck.js` | 端到端自检（`/facts`）：把真机结论一次性问清（版本 / WASM / 热循环 / fs 回环 / spawn / 探活） |

## 与消费方的关系

库**不替消费方决定**它的服务怎么起（`pi-web` 的启动方式属于消费方）。本目录提供的是：

1. **可直接复制的 bootstrap 范式**（含注意事项）；
2. **自检脚本**，用来在真机上判断"环境到底能不能用"。

## 载荷分发契约（工程规划 §5.5 / §5.10 ⑩）

- **首选**：应用载荷放 `resources/resfile/<app>/`，Node 从**只读安装目录直读**（零解压，免掉首启解压数万文件的耗时与失败面）；
- **仅当载荷必须可写时**才用 `tar.gz` + **Node 自己解包**（谁写谁读：ArkTS/鸿蒙解压器写出的文件 Node 读不到，notes 硬约束 ④）；
- 运行时**不要**依赖 `process.cwd()`（真机上是 `/`），一律用绝对路径。
